# Features

## Anders als andere

Kabel-Kopf ist **keine ChatGPT-Hülle** und **kein KI-Wrapper**. Das Produkt ist das
persönliche Erfahrungswissen eines Handwerkers – lokal, offline, vertraulich. KI
verstärkt dieses Wissen später nur optional.

## Paywall-Philosophie

- **Free:** alle Kernfunktionen unbegrenzt nutzbar, komplett lokal.
- **Pro (optional, später):** Zeit sparen, keine Grundfunktionen freischalten –
  KI, Cloud-Sync, Team, erweiterte Analyse, OCR.
- Keine künstlichen Kontingente (keine „3 PDFs/Monat"), keine wegnehmenden Sperren.
